A small program that draws one image summing up Sunday 22 November 2026 world news to `/output/entry.png`. The front page covers 35 stories across 7 regions with 14 flat-drawn illustrations: the overnight Gulf escalation (Iran hits four US bases in Bahrain and three tankers in the Strait of Hormuz), the COP31 final deal unveiled at dawn in Antalya, Rishabh Pant's record 128 in Wellington on day four of the Test, plus France taking Myanmar to the UN Security Council, the US curbing military ties with Canada, Denmark expelling a Russian attaché, and 29 more stories — with a world map of numbered pins, a "day in numbers" strip, per-region counts, and a DATE CHECK footer naming the stories left out as other days' news. Every story on the page was reported on 22 November 2026, with its wire source (Reuters, AP, AFP, Al Jazeera, PTI, AAP, Arab News) printed beside it. The image is drawn entirely in code with Pillow — no network, no external files — so the program is deterministic: two runs write the same bytes.

## Run it

```sh
python3 main.py
```
